# Mobile Sales Dashboard

##  Project Overview

This project presents an interactive **Mobile Sales Dashboard** designed to analyze mobile phone sales performance and provide clear insights into sales trends, customer behavior, and overall business performance.

The dashboard transforms raw sales data into meaningful visualizations and key performance indicators, making it easier to identify patterns, compare performance across different dimensions, and support data-driven decision-making.

##  Tools & Technologies

* **Power BI** – Data visualization and dashboard development
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and analytical metrics
* **Excel/CSV** – Source data

##  Key Metrics & Analysis

The dashboard provides insights into:

* Total sales and revenue
* Total quantity sold
* Number of transactions
* Average sales value
* Sales performance over time
* Sales distribution across different mobile brands
* Performance by mobile model
* Geographic sales analysis
* Customer purchasing patterns
* Payment method analysis
* Comparison of sales performance across different categories

##  Dashboard Features

The interactive dashboard includes:

* KPI cards for quick performance tracking
* Time-based sales analysis
* Brand and model-level comparisons
* Geographic visualization of sales
* Interactive filters and slicers
* Dynamic charts for exploring different aspects of the sales data
* User-friendly layout for quick business insights

##  Project Objective

The primary objective of this project is to demonstrate the ability to transform raw sales data into an **interactive business intelligence dashboard** that communicates important insights clearly and effectively.

It also demonstrates practical experience with **data cleaning, data modeling, DAX, and Power BI visualization techniques**.
